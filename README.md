# PhishEye

PhishEye — приложение для выявления потенциально фишинговых URL-адресов с использованием машинного обучения и анализа структуры ссылок.

## Основные возможности

- Оценка потенциального риска URL с помощью гибридной модели машинного обучения.
- Анализ структурных признаков ссылки.
- Вывод оценки фишингового риска и обнаруженных особенностей.
- Пояснение результатов проверки.

## Состав проекта

- `server.py` — серверная часть приложения.
- `index.html` — пользовательский интерфейс.
- `features.py` — извлечение структурных признаков URL.
- `phisheye_hybrid_model_hardnegatives.pkl` — обученная модель.
- `requirements.txt` — зависимости Python.

## Запуск

1. Установить Python.
2. Установить зависимости:

   pip install -r requirements.txt

3. Запустить приложение:

   python server.py

4. Открыть в браузере:

   http://127.0.0.1:8000

## Важное замечание

Результаты анализа являются оценкой модели и не гарантируют безопасность или обнаружение всех фишинговых ссылок.
